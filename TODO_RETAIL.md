# BoxCRM (Retail) — План развития и масштабирования

Текущий статус: **MVP v1.0 (Пауза)**
Реализован базовый учет товаров, одиночные продажи, списания, роли и простая аналитика на SQLite.

## 1. Рабочее место кассира (РМК) и чеки
- **Корзина (мульти-чек):** возможность добавлять в один чек несколько разных товаров перед оплатой.
- **Расчет сдачи:** поле «Внесено наличными» с быстрыми кнопками номиналов (500, 1000, 2000, 5000 ₽) и автоматическим расчетом сдачи.
- **Возвраты:** оформление возврата товара от покупателя с возвратом остатка на склад и корректировкой кассы.
- *Файлы для создания/изменения:* `shop/models.py` (модели `SaleReceipt` и `SaleItem`), `shop/templates/shop/pos.html` (новый экран кассира), `shop/static/shop/js/pos.js`.

## 2. Торговое оборудование (54-ФЗ и железо)
- **Сканер штрихкодов:** добавить поле `barcode` в модель товара и перехват ввода с USB/Bluetooth-сканера на экране кассы.
- **Фискальный регистратор (Атол / Штрих-М):** интеграция с локальным Web-сервером драйвера ККТ для печати фискальных чеков.
- **Денежный ящик:** отправка импульса на открытие ящика через ККТ только при закрытии чека с оплатой наличными.
- **Реквизиты 54-ФЗ:** настройки СНО (УСН/Патент), ставки НДС и признака предмета расчета.
- *Файлы для создания/изменения:* `shop/services/kkt_atol.py` (модуль отправки JSON-команд на драйвер кассы), `core/models.py` (настройки магазина и ИНН).

## 3. Склад и закупки
- **Приемка товара (накладные):** оформление поступления партии товара от поставщиков вместо ручного редактирования остатков.
- **Инвентаризация:** режим сверки фактических остатков с учетными и автоматическое списание недостачи.
- *Файлы для создания/изменения:* `shop/models.py` (модели `Supplier`, `SupplyInvoice`), `shop/views_supply.py`.

## 4. Инфраструктура и облако
- **База данных:** миграция с SQLite на PostgreSQL для одновременной работы кассира и владельца с разных устройств.
- **PWA / Офлайн-буфер:** локальное сохранение чеков в браузере при обрыве интернета с последующей синхронизацией.
- *Файлы для создания/изменения:* `config/settings.py`, `static/manifest.json`, `static/sw.js`.
